바이트

공백 포함 글자수는 띄어쓰기와 줄바꿈까지 모두 센 값, 공백 제외 글자수는 이를 뺀 값입니다. 바이트는 UTF-8 기준 한글 1자 3바이트, 영문·숫자 1바이트로 계산합니다. 채용 사이트마다 기준이 달라 공고의 글자수 기준이 ‘공백 포함’인지 꼭 확인하세요.

사용 방법

  1. 입력창에 글을 쓰거나 붙여 넣습니다.
  2. 아래 숫자가 실시간으로 바뀝니다.
  3. 다시 쓰려면 전체 지우기를 누릅니다.

계산 방법

바이트(UTF-8) = 한글·한자 3 + 영문·숫자·기호 1 + 줄바꿈 1
EUC-KR(완성형) 기준이면 한글 1자 = 2바이트

자주 쓰는 분량 기준

용도흔한 기준
자기소개서 문항500자·700자·1,000자 (공백 포함이 일반적)
문자 메시지단문 90바이트, 장문 2,000바이트 (EUC-KR 기준)
검색 결과 제목약 30자 안팎에서 잘림
검색 결과 설명약 80~120자 안팎

채용 시스템마다 줄바꿈을 1자 또는 2자로 세거나, 바이트로 제한하는 경우가 있습니다. 제한에 딱 맞추기보다 10~20자 여유를 두는 것이 안전합니다.

자주 묻는 질문

입력한 글이 저장되거나 전송되나요?

아니요. 모든 계산은 브라우저 안에서 이뤄지며 서버로 보내지 않습니다. 창을 닫으면 사라집니다.

단어 수는 어떻게 세나요?

띄어쓰기로 나뉜 덩어리를 한 단어로 셉니다. 한국어 어절 수와 같습니다.

문장 수 기준은 무엇인가요?

마침표, 물음표, 느낌표로 끝나는 단위를 한 문장으로 셉니다. 마침표 없는 마지막 줄도 한 문장으로 계산됩니다.

공백 포함과 공백 제외는 언제 쓰나요?

자기소개서·지원서는 기관마다 기준이 달라 공고문에 적힌 기준을 따릅니다. 따로 없으면 공백 포함으로 세는 경우가 많습니다.

자소서 1,000자는 A4 몇 장인가요?

글꼴과 줄 간격에 따라 다르지만, 보통 10~11pt 기준 A4 3분의 2쪽 안팎입니다.

바이트 수는 왜 보나요?

문자 메시지나 일부 시스템 입력란이 글자 수 대신 바이트로 길이를 제한하기 때문입니다. 한글은 바이트를 더 많이 차지합니다.

이 계산기를 내 블로그·홈페이지에 넣기

아래 코드를 복사해 HTML 편집 화면에 붙여 넣으면 계산기가 그대로 들어갑니다. 무료이며, 출처 링크만 지워지지 않게 두면 됩니다. 티스토리·워드프레스·개인 홈페이지에서 쓸 수 있고, 네이버 블로그는 외부 코드를 막아 두어 링크로 공유하는 편이 좋습니다.

계산 결과는 입력값과 일반적인 기준을 바탕으로 한 참고용 추정치이며 법적 효력이 없습니다. 입력값은 브라우저 안에서만 처리되고 저장·전송되지 않습니다. 오류를 발견하면 문의하기로 알려 주세요.
