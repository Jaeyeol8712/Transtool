# 인스타 새 컨셉 초안 (2026-10-28, 대표 지시: "이런 식으로 올리면 누가 봐, 벤치마킹해서 재밌게 다시")

## 근거(검색으로 확인한 것만)
- 계정이 한 주제를 일관되게 다룰수록 안정적으로 노출되고, 저장·공유·프로필 방문·DM·링크 클릭을 중요 신호로 본다(수치 가중치는 글에 없음). 출처: https://blog.highoutputclub.com/2026-instagram-algorithm-update/
- 릴스는 유입, 카드뉴스는 이해·설득·저장, 스토리는 관계. 핵심은 '저장 버튼을 누르게 하는 기획'. 시리즈로 묶으면 축적 효과. 출처: https://brunch.co.kr/@mobiinside/7266
- 해시태그는 게시물당 최대 5개, 노출의 핵심은 아님. 캐러셀 최대 20장.
- 한계: 개별 경쟁 계정은 인스타를 직접 열 수 없어 못 봤다. 대표가 마음에 든 계정 2~3개를 주면 훅·구성을 분석해 반영.

## 지금 문제
첫 게시물은 '정보 전달'뿐이라 볼 이유·저장할 이유·보낼 사람이 없다. 첫 장에 질문/갈등이 없고, 계정이 무슨 계정인지 한 줄로 안 보인다.

## 새 컨셉: "계산 대신 해주는 계정"
한 줄: 월급·알바·직장 돈 계산을 30초 안에 끝내 준다. 말투는 친구가 알려주듯 짧게.

### 고정 시리즈 4개 (주 3회까지, 처음엔 주 2~3회)
1. **월급 vs 통장** — 첫 장 "월급 300만원인데 통장엔 얼마?" → 공제 항목을 큰 숫자로 한 장씩 → 마지막 장 "내 월급은 프로필 링크 계산기". 요율은 공식 출처 확인된 것만.
2. **이거 나만 몰랐어?(퀴즈)** — 첫 장 질문(예: 주 15시간 미만 알바도 주휴수당 받나?) → 2장 "정답은 다음 장" → 근거 → 마지막 장 "알바하는 친구에게 보내기". 공유 유도.
3. **N년차 비교** — 같은 계산을 상황 두 가지로 나란히(예: 연차 1년 미만 vs 1년 이상). 저장하기 좋은 표 한 장.
4. **이번 달 챙길 것(월 1회)** — 달력형 체크리스트. 저장 유도.
(릴스는 데이터 보고 나서: 15초 '이 계산 틀리기 쉬워요' — 제작 부담 때문에 보류.)

### 장 구성 규칙
- 1장: 질문 또는 숫자 충돌 한 줄(훅). 2~N-1장: 한 장 한 메시지, 숫자는 크게. 마지막 장: '저장해 두기' 또는 '친구에게 보내기' + 프로필 링크 안내.
- 캡션 2줄 + 출처 한 줄 + 해시태그 5개 이내.
- 지어낸 수치·후기 금지. 광고 표시는 추천 글(제휴) 안에서만 — 인스타에서는 제휴 링크를 올리지 않는다.

### 측정(Metricool)
도달 대비 저장·공유 비율, 프로필 방문, 프로필 링크 유입(utm_source=instagram). 첫 5개 게시 후 시리즈별 비교해서 잘 되는 것만 남긴다.

### 이미 만든 카드 3세트 처리
- 최저임금(게시됨): 그대로 둔다. 다음 '월급 vs 통장' 시리즈 예고용으로 댓글에 질문 하나.
- 실업급여·연차: 예약 전에 1장에 훅 질문을 넣어 퀴즈형으로 다시 만든다(정보 카드 그대로 올리지 않음).
