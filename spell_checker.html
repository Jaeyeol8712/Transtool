맞춤법 검사기

한국인이 자주 틀리는 표현을 찾아 바른 표기를 알려줍니다.

생활툴 · 텍스트최종 수정 2026.10.23로그인 없이 무료

    이 검사기는 자주 틀리는 표현 목록과 대조하는 방식입니다. ‘안되요 → 안 돼요’, ‘몇일 → 며칠’, ‘금새 → 금세’처럼 틀린 표기가 있으면 빨간 밑줄과 함께 바른 표기를 보여줍니다. 문맥을 이해하는 검사는 아니므로 중요한 문서는 국립국어원 표준국어대사전으로 한 번 더 확인하세요.

    사용 방법

    1. 검사할 문장을 붙여 넣습니다.
    2. 맞춤법 검사를 누르면 틀린 표현이 표시되고 아래에 고칠 목록이 나옵니다.
    3. ‘고친 문장 복사’로 수정된 전체 문장을 복사할 수 있습니다.

    가장 많이 틀리는 다섯 가지

    • 돼 / 되: ‘되어’로 바꿔 말이 되면 ‘돼’입니다. 안 돼요(안 되어요), 됐다(되었다).
    • 며칠: ‘몇 일’로 쓰지 않습니다. 오늘이 며칠이에요?
    • 금세: ‘금시에’가 줄어든 말이라 ‘금새’가 아닙니다.
    • 웬 / 왠: ‘왠지’만 ‘왠’을 쓰고 나머지는 모두 ‘웬’입니다. 웬일, 웬만하면.
    • -이 / -히: 깨끗이, 일일이, 곰곰이, 틈틈이는 ‘-이’로 씁니다.

    자주 묻는 질문

    입력한 글이 외부로 전송되나요?

    아니요. 검사는 브라우저 안에서 목록과 대조하는 방식이라 어떤 내용도 서버로 보내지 않습니다.

    모든 맞춤법 오류를 찾나요?

    아닙니다. 자주 틀리는 표현 위주로 검사하며 문맥이 필요한 오류(로서/로써, 결재/결제 등)는 찾지 못합니다.

    띄어쓰기도 검사하나요?

    ‘할 수 있다’, ‘하는 것’처럼 의존명사 띄어쓰기는 띄어쓰기 검사기에서 따로 확인할 수 있습니다.

    함께 보면 좋은 계산기

    • 띄어쓰기 검사 계산기 — ‘할수있다’, ‘하는것’, ‘갈때’처럼 의존명사를 붙여 쓴 부분을 찾아 띄어쓰기를 고쳐 줍니다. 입력…
    • 글자수 세기 계산기 — 자기소개서·블로그 원고를 붙여 넣으면 공백 포함·공백 제외 글자수, 단어 수, 문장 수, 줄 수,…
    • 취업운세 계산기 — 이름을 넣으면 오늘의 취업·면접 응원 메시지를 무작위로 보여주는 재미용 도구입니다. 결과는 과학적 근거가…
    • QR코드 생성 계산기 — 웹사이트 주소나 텍스트를 넣으면 브라우저에서 바로 QR코드를 만들고 PNG 이미지로 내려받을 수 있습니다.…

    이 계산기를 내 블로그·홈페이지에 넣기

    아래 코드를 복사해 HTML 편집 화면에 붙여 넣으면 계산기가 그대로 들어갑니다. 무료이며, 출처 링크만 지워지지 않게 두면 됩니다. 티스토리·워드프레스·개인 홈페이지에서 쓸 수 있고, 네이버 블로그는 외부 코드를 막아 두어 링크로 공유하는 편이 좋습니다.

    계산 결과는 입력값과 일반적인 기준을 바탕으로 한 참고용 추정치이며 법적 효력이 없습니다. 입력값은 브라우저 안에서만 처리되고 저장·전송되지 않습니다. 오류를 발견하면 문의하기로 알려 주세요.
