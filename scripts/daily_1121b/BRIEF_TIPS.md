# 명소 안내·꿀팁 작성 브리프 (2026-11-21 2차)

목표: K링크(aroundtool.com/klink) 장소 상세 화면에 나오는 '명소 안내'를 채운다. 화면에서 tips는 장소 이름 바로 아래 노란 박스 '즐기는 꿀팁'으로 보인다.

## 출력 형식 (파이썬 파일, UTF-8)
지정한 파일에 아래 형식으로만 쓴다. 다른 파일은 고치지 않는다.

```python
# -*- coding: utf-8 -*-
"""2026-11-21(2차) 꿀팁 채우기. 못 쓴 곳: (id 이름 — 이유) 또는 없음"""
SPOTS = {
 "insa": dict(
   one="한 문장 요약(해요체, 40~70자).",
   see=[("볼거리1", "한 줄 설명"), ("볼거리2", "..."), ("볼거리3", "...")],   # 정확히 3개
   facts=dict(hours="운영 시간 (휴무 포함)", fee="요금 또는 '입장 무료'", stay="약 1시간", when="추천 시간대(오전/낮/해 질 무렵/저녁 등)", access="역·출구 또는 주소"),
   tips=["구체적 꿀팁 한 문장.", "...", "..."],   # 2~3개
   src=[("기관명 — 페이지 제목", "https://..."), ("...", "https://...")],   # 1~3개
   checked="2026-11-21", photo=None),
}
```

## 규칙
- 사실은 공식 출처로 확인한다: 공식 사이트, 한국관광공사(visitkorea.or.kr·VISIT SEOUL korean.visitseoul.net·english.visitkorea.or.kr), 서울시·구청·지자체, 해외는 각 시설 공식 사이트·현지 관광청(osaka-info.jp 등)·일본정부관광국(JNTO). 블로그·여행사 후기는 근거로 쓰지 않는다(보도기사는 공식 발표를 인용한 경우만 보조로).
- WebSearch로 찾고, 필요하면 web-fetch 계열 도구로 페이지를 읽어 숫자를 확인한다.
- 모르는/확인 못 한 운영 시간·요금은 지어내지 말고 '방문 전 확인'으로 쓴다. 바뀔 수 있는 숫자는 '약' 또는 '(2026년 기준)'처럼 기준을 붙인다.
- tips는 실제로 즐기는 데 도움이 되는 구체적 한 문장: 휴무일·휴관일, 붐비는 시간 피하기, 예약·입장권 방법, 야경·공연 시간, 동선·출구, 현금/카드, 택스리펀 등. "즐거운 시간 보내세요" 같은 빈말 금지. 후기처럼("가 봤더니") 쓰지 않는다.
- 가게 이름은 공식 출처가 있을 때만. 광고·예약 대행 문구 금지.
- 해요체, 짧은 문장. 띄어쓰기: "3,000원", "약 2시간", "10:00~17:00".
- 각 장소당 공식 출처 최소 1개. 확인을 전혀 못 하면 그 장소는 빼고 docstring '못 쓴 곳'에 이유를 적는다.
- 끝나면 `python3 -c "import ast,sys;ast.parse(open('파일').read())"`로 문법 확인.
- 마지막 답변: 쓴 장소 수, 못 쓴 곳과 이유, 확인이 애매했던 숫자 목록(3~6줄).
